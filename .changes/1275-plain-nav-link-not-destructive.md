### Added

- **`@reticlehq/core`: the plumbing for a plain-navigation exemption, held in the safe direction.** The destructive guard reads a control's `href` along with its text, which is right for a button whose label is an icon, since its `formAction` is the only place it says what it does. On an anchor the href is an ADDRESS, and addresses carry the pattern's words, so `Orders & invoices` pointing at `/billing/payment` is refused for the `payment` in the URL, and the way past a refusal is `confirmDangerous: true` passed reflexively. The classifier now takes the element facts from a caller that has the element, and `isPlainNavigationLink` grants the exemption only on a positive reading: the href must use a scheme that fetches a document, the link must be a real anchor rather than a `role="link"` on a `div`, it must not sit inside a form, the click-handler question must be answered, and the anchor must not carry a framework's marker for a rewritten non-GET request (`data-method`, `data-turbo-method`, `data-remote`, htmx verbs).

  It does not yet exempt a real page, and that is stated rather than implied. The exemption needs `hasClickHandler: false`, and no shipped producer supplies one: the React adapter answers `true` or `undefined`, since props are the only thing a fibre exposes and it can prove a handler exists but never that none does, and no other adapter registers a probe, so any other page reads `undefined` too. A page with no adapter and a handler bound with plain `addEventListener` are indistinguishable from outside, so the honest reading there is "unknown", and unknown refuses. The reported link is therefore still blocked on every page, and the tests that show the exemption firing install a probe that reads the element directly, which models a page where that reading is obtainable. What ships is the narrowing and the wiring, ready for a producer that can answer `false`. Refs [#1275](https://github.com/reticlehq/reticle/issues/1275).

- **`@reticlehq/browser`: the non-GET marker reaches the native path.** `data-method`, `data-turbo-method`, `data-remote` and the htmx verbs render an `<a href>` that reads as a GET, with no handler any attribute check can find, and intercept the click in script to issue a DELETE. `inspect` now reports `nonGetMarker` beside `isAnchor`, `hasClickHandler` and `insideForm`, and the server-side guard refuses on it when a descriptor carries it.
